## Project Decision
I decided to use a Task Manager application as my main practice project throughout the Ruby on Rails training. It will serve as a hands-on project where I can apply the concepts, techniques, and features I learn in each training session.

## Project Overview
The Task Manager is a basic CRUD application built with Ruby on Rails and PostgreSQL. It allows users to create, view, update, and delete tasks.
