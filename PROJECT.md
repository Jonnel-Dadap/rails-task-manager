# TASKORA

**Personal Task Management System**

**Tagline:** Plan Better. Work Smarter.

## 1. Project Overview

TASKORA is a web-based Personal Task Management System built with Ruby on Rails. It allows users to manage their personal tasks, organize priorities, set deadlines, and monitor their progress through a personal dashboard.

## 2. Main Objectives

- Provide a simple platform for managing personal tasks.
- Help users organize tasks by status and priority.
- Allow users to track deadlines and task progress.
- Provide secure account and profile management.
- Ensure users can only access their own tasks.

## 3. Core Features

1. **User Authentication** – Registration, login, and logout.
2. **Personal Dashboard** – Overview of total, pending, in-progress, completed, and overdue tasks.
3. **Task Management** – Create, view, update, and delete personal tasks.
4. **Task Organization** – Search, status filters, priority levels, and due dates.
5. **Profile Management** – Update name, email, and password.

## 4. Task Information

Each task will have:

- Title
- Description
- Status: Pending, In Progress, Completed
- Priority: Low, Medium, High
- Due Date

## 5. Technology Stack

- **Backend:** Ruby on Rails
- **Database:** PostgreSQL
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Version Control:** Git and GitHub

## 6. Expected Output

A functional personal task management application where users can securely manage their accounts, organize tasks, set priorities, track deadlines, and monitor their progress.
