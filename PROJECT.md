# TASKORA

**Personal Task Management System**

**Tagline:** Plan Better. Work Smarter.

## 1. Project Overview

TASKORA is a web-based Personal Task Management System built with Ruby on Rails. It allows users to create, manage, update, and organize their personal tasks in one centralized workspace.

The system provides task status tracking and archive management to help users maintain an organized workspace and monitor their task progress.

## 2. Main Objectives

- Provide a simple platform for managing personal tasks.
- Help users organize tasks through status tracking.
- Allow users to monitor task progress.
- Provide archive and restore functionality for better task organization.
- Ensure users can only access and manage their own tasks.
- Provide a secure and user-friendly application.

## 3. Core Features

1. **User Authentication** – User registration, login, and logout.
2. **Task Management** – Create, view, update, and delete personal tasks.
3. **Task Status Management** – Organize tasks according to their current status.
4. **Archive Management** – Archive tasks to keep the active workspace organized.
5. **Restore Tasks** – Restore previously archived tasks to the active task list.
6. **Permanent Task Deletion** – Permanently delete archived tasks when they are no longer needed.

## 4. Task Information

Each task contains the following information:

- **Title** – The name or main subject of the task.
- **Description** – Additional details or information about the task.
- **Status** – The current progress of the task.

### Available Task Statuses

- Pending
- In Progress
- Completed

## 5. Technology Stack

- **Backend:** Ruby on Rails
- **Database:** PostgreSQL
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Authentication:** Devise
- **Version Control:** Git and GitHub

## 6. Expected Output

A functional Personal Task Management System where users can securely manage their personal tasks, monitor task statuses, and maintain an organized workspace through archiving, restoring, and deleting tasks.
